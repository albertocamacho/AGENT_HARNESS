# Anti-Patterns: The AI Slop Test

If someone could look at this page and immediately say "AI made this," you've failed. These are the fingerprints of generic AI output from 2024-2025. Avoid every single one.

## The AI Color Palette
- Cyan-on-dark, purple-to-blue gradients, neon accents on dark backgrounds
- Gradient text on metrics or headings — decorative, not meaningful
- Dark mode with glowing accents — looks "cool" without actual design decisions
- Pure black (#000) or pure white (#fff) — always tint; these never appear in nature

## The AI Layout
- Identical card grids: same-sized cards with icon + heading + text, repeated endlessly
- Hero metric layout: big number, small label, supporting stats, gradient accent
- Everything centered — left-aligned with asymmetric layouts feels more designed
- Everything in cards — spacing and alignment create grouping naturally
- Cards nested inside cards — flatten the hierarchy with typography and dividers
- Same spacing everywhere — without rhythm, layouts feel monotonous

## The AI Aesthetic
- Glassmorphism everywhere: blur effects, glass cards, glow borders used decoratively
- Rounded rectangles with generic drop shadows — safe, forgettable
- Rounded element with thick colored border on one side — lazy accent
- Sparklines as decoration — tiny charts that look sophisticated but convey nothing
- Large icons with rounded corners above every heading — templated
- Monospace typography as shorthand for "technical/developer" vibes

## The AI Font Stack
- Inter, Roboto, Arial, Open Sans, Lato, Montserrat — these are everywhere
- Better alternatives: Instrument Sans, Plus Jakarta Sans, Outfit, Onest, Figtree, DM Sans
- For editorial/premium: Fraunces, Newsreader, Lora

## The AI Motion
- Bounce or elastic easing — dated, tacky; real objects decelerate smoothly
- Animating everything — animation fatigue is real
- Using >500ms for UI feedback — feels sluggish

## The AI Copy
- Redundant headers that restate what's already visible
- Every button is primary — hierarchy matters
- Generic "Welcome to..." hero text
- "Click here" link text
- "Something went wrong" without explanation

## The Test
Review your output against this list. Count the tells. If you find even one, fix it. A distinctive interface makes someone ask "how was this made?" not "which AI made this?"
